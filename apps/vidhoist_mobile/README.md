# Vidhoist for Android

The phone app: paste a link, pick a quality, keep the file in
`Download/Vidhoist`. Its library is a scan of that folder, with its own
player, playlists and transcripts.

- Identity: `com.yasir.vidhoist`, label "Vidhoist", launcher icons in
  `assets/icons/` generated by `tool/icons/vidhoist_kit.py` then
  `dart run flutter_launcher_icons`.
- Build: `flutter build apk --debug` here; release builds need a
  `key.properties` and keystore that are not in the repository.
- Tests: `flutter test --no-pub`; every screen goes through
  `test/device_matrix.dart` (`expectNoOverflow`).

The download engine is being moved from a Vidhoist server to yt-dlp on the
device; see `docs/blueprint/REPORT.md` at the repository root.
