# vh_ytdlp

Pure Dart, shared by both VidHoist apps: the yt-dlp command lines, and
reading what yt-dlp prints (progress, the file written, the info JSON,
errors and its version). It runs no process itself; each app runs yt-dlp
its own way. Measurements and traps are in docs/ENGINE.md. Part of the
VidHoist monorepo; see the README at the repository root.
