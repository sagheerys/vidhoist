# vh_transcripts

Pure Dart, shared by both VidHoist apps: reading subtitle files into
transcripts, fetching the subtitles of a clip already in the library with
yt-dlp, chapters and reading text drawn from a transcript, the search over
what was said (Arabic folded, so a word typed without its marks still finds
it), and the store that keeps them. Part of the VidHoist monorepo; see the
README at the repository root.
